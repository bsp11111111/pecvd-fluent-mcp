# 测试与验收记录

日期：2026-10-28。接入包版本：0.1.0。目标求解器：ANSYS Fluent 2024 R1。

## 已执行

在全新、未继承系统包的 Python 虚拟环境中，从 `pyproject.toml` 安装本包和全部依赖。测试主机为 Linux，Python 3.12.14；Windows 安装指南建议 Python 3.11。`pip check` 返回 `No broken requirements found`。

`python -m unittest discover -s tests -v`：**12 项测试通过**。

覆盖内容：

- 2 Torr 与 sccm 的单位换算、混合物分子量和质量流量。
- 三种连接测试网格的拓扑数量、开孔区域分配、正单元面积和总面积。
- 已存在工程不覆盖、非法网格参数拒绝、文件越界与符号链接限制。
- 净通量到 nm/min／Å/min 的换算、径向面积加权平均和全片 SVG 生成。
- 非法密度、负通量、不完整晶圆范围及外部等离子体 CSV 范围检查。
- 版本枚举适配、错误求解器版本关闭、许可证启动失败不产生虚假 case 文件。
- 实际 STDIO MCP 子进程握手、发现 **13 个工具**、正常调用与错误返回。
- 使用官方 PyFluent `settings_241` 生成类核对配置代码引用的设置路径。

另用独立的 meshio 5.3.5 读取三份默认 Fluent ASCII 网格，均读得 3325 个节点、6492 个面。meshio 对 Fluent 区域名／类型定义提示未支持，因此此检查只证明坐标和面数据可解析，不能代替 Fluent 原生区域／体积检查。

Word 操作手册已做 DOCX 压缩结构完整性检查。源码已通过 Python 编译检查。开发测试中的制造解和模拟会话只存在于测试代码，未作为科研模拟结果提供。

## 尚需在使用者电脑验收

- Windows Python 3.11、双击安装脚本与实际客户端配置。
- 2024 R1 可执行文件定位、GUI 自动启动和可用许可证。
- Fluent 原生网格读取、正体积、边界区域类型及轴对称单位。
- Fluent 实际接受物性／边界赋值、初始化、迭代和 case/data 保存。
- 进出口质量守恒、收敛与精度；连接测试物性不具备科研验证效力。
